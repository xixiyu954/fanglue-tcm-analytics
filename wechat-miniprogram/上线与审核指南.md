# 📱 「方略随身」微信小程序导入、注册与过审指南

## 一、零注册 1 分钟立即预览（现在就能跑！）

你的电脑已经装好了 **微信开发者工具**：
1. 打开 **微信开发者工具**，用手机微信扫码登录；
2. 点击 **「导入项目」**：
   - **项目目录**：选择 `C:\Users\Administrator\.gemini\antigravity\scratch\fanglue\wechat-miniprogram`
   - **AppID**：点击输入框右侧的 **「测试号」**（无需先注册！）
3. 点「导入」即可立刻看到 4 个完整页面（每日辨方、方剂体检、错题图谱、我的与药典速查）；
4. 点顶部 **「预览」**，手机微信扫一扫就能直接在自己手机上刷题体验！

## 二、免费注册个人主体 AppID（发给全班同学用的前提）

1. 浏览器打开微信公众平台：https://mp.weixin.qq.com → 点击右上角 **「立即注册」→「小程序」**；
2. 填写一个**未注册过公众号/小程序的邮箱**，验证后选择主体类型：**「个人」**；
3. 按页面提示填写本人姓名、身份证号并微信扫码实名验证（约 3 分钟完成，免费）；
4. 登录后台后，在左侧 **「开发管理 → 开发设置」** 复制你的 **AppID**（形如 `wx1234567890abcdef`）；
5. 打开 `wechat-miniprogram/project.config.json`，把 `"appid": "touristappid"` 替换成你的真实 AppID。

---

## 三、一键开通微信云开发（免服务器、免备案、收集真实 OpenID 埋点）

1. 替换真实 AppID 后，在微信开发者工具顶部工具栏点击 **「云开发」** 按钮，按引导免费开通一个新环境（记录**环境 ID**，形如 `cloud1-xxxxxxx`）；
2. 在云开发控制台 → **「数据库」** 中新建 4 个集合（权限保持默认的“仅创建者可读写”即可，因为我们通过云函数安全写入）：
   - `dim_user`
   - `fact_quiz_log`
   - `fact_event`
   - `fact_share`
3. 在微信开发者工具左侧目录中，右键 `cloudfunctions/logEvent` → **「上传并部署：云端安装依赖」**；同样部署 `cloudfunctions/exportAnalytics`；
4. 打开 `miniprogram/app.js` 第 6 行，填入你的云环境 ID：`const CLOUD_ENV_ID = '你的环境ID';`；
5. 保存后，所有同学的真实匿名学习日志（服务端自动对 `OPENID` 做 SHA-256 脱敏）就会实时写入云数据库！

## 四、体验版冷启动 & 个人主体过审避坑清单

1. **先用体验版给同学试用**：点微信开发者工具右上角 **「上传」** → 在微信公众平台 **「版本管理」** 设为体验版 → 扫码发给班级 20–40 位同学试用 1–2 周；
2. **提交正式审核要点**：
   - **服务类目**：优先选 **「工具 → 信息查询 / 效率」** 或 **「教育 → 备考/学习工具」**（以后台个人主体当前开放选项为准，**绝对不要选医疗健康类目**）；
   - **小程序名称建议**：如「方略方剂笔记」「本草方剂自测」「方略辨方卡」（避开“诊疗/医馆/药房/处方”等医疗敏感词）；
   - **隐私协议**：在公众平台「设置 → 服务内容声明 → 用户隐私保护指引」中声明不收集手机号、地理位置、相册等敏感权限（本项目零敏感权限，过审极快！）；
3. **数据回流到方略分析平台**：
   - 在云开发控制台导出 4 张表 JSON（或在测试期用小程序「我的 → 复制匿名埋点 JSON」），直接上传到 **https://fanglue-tcm.streamlit.app** 的 **「📱 小程序增长与 A/B 实验」** 页面，即可一键出 Cohort 留存热力图、A/B 检验报告、Jaccard 混淆相关性检验与裂变 K 因子！
